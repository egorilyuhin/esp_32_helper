# ЧТО ЗА ПРОЕКТ
Этот проект создан для того чтобы объяснить работу с дисплейным модулем TZT 0,96 OLED esp1306 для esp32

# Cхема подключения
Для подключения к esp32 необходимо установить драйвера esp1306, для этого скачайте файл - https://github.com/stlehmann/micropython-ssd1306/blob/master/ssd1306.py
и сохраните его на esp32 с названием esp1306_display.py

Распиновка

Дисплей___________Рекомендованный цвет___________ESP32

VCC_____________________красный__________________3.3V

GND_____________________черный___________________GND

SCL_____________________желтый_________________GPIO 22

SDA_____________________синий__________________GPIO 21


пин VCC - 3.3V отвечает за питание 3.3V НЕ ПОДКЛЮЧАЙТЕ 5V!!!!!

пин GND - GND овтечает за заземление(отвод питания обратно)

пин SCL - GPIO 22 отвечает за такт передачи информации на дисплец

пин SDA - GPIO 21 отвечает за передачу информации

# Бытсрый старт

from machine import Pin, I2C
import ssd1306_display
import framebuf
import time

# Настройка I2C
i2c = I2C(0, scl=Pin(22), sda=Pin(21))

# Создание объекта дисплея (128x64, адрес обычно 0x3C)
oled = ssd1306_display.SSD1306_I2C(128, 64, i2c, addr=0x3C)

# Очистка экрана по средству отключения рабочих пикселей
oled.fill(0)

# Вывод текста
oled.text('ESP32', 0, 0)
oled.text('English Display!', 0, 16)
oled.text('Mac OS', 80, 57)

# Показываем на экране
oled.show()
